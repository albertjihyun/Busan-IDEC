## 3.8 한계와 후속 과제

한계마다 그 한계를 줄이는 후속 과제를 짝으로 적는다.

### 판정

| 한계 | 근거 | 후속 과제 |
|---|---|---|
| 판별력 상한이 신호에 묶여 있다 | 졸음 효과 1.3% 대 각성 중 흔들림 4.0%, 이론 AUC 0.59 | 심박 외 채널 결합, 사람별 이상탐지 모델 |
| 졸음 판정 성능이 한 데이터셋 안의 점수다 | 모든 성능이 MPD-DF(시뮬레이터, 수면 박탈 없음, 시속 35 km) 안에서 나왔다. 실도로에서 졸음을 버티려는 노력은 심박을 다른 방향으로 움직일 수 있다[34] | 다른 졸음 라벨 데이터와 실도로 조건으로 재검증 |
| 배포 문턱은 교차검증된 값이 아니다 | 50명 전체로 잡은 문턱 | 외부 데이터로 문턱 재확인 |
| 출발부터 졸린 운전자는 감지하지 못한다 | 기준선이 졸음 상태로 잡힌다 | 대상을 출발 시 각성 운전으로 한정(2.2) |
| 오래 앉아 있으면 심박이 내려가 헛경보가 후반에 몰린다 | 90분 뒤 각성 창의 31%가 문턱을 넘는다(시작 20분 안은 4~8%). 기준선을 따라 움직이게 하는 방법은 시험했고 손해라 두지 않았다(3.4.3) | 한계로 남긴다 |
| 운전 중 이마에서 판정이 얼마나 남는지 모른다 | 판정 창이 이마 야외 활동 약 38%, 손목 운전 26% | 보드 착용 실측 뒤 창 품질 문턱(`KEEP_K`) 조정 |

### 신호처리

| 한계 | 근거 | 후속 과제 |
|---|---|---|
| 접촉 교란 구간을 신호 품질 검사가 놓친다 | 실측 480초에서 교란 구간(340~353초)의 과도가 2초 창 진폭을 높게 유지해 검사를 통과, 이중 검출 발생(3.3.7) | 평소 진폭 대비 상대 검사, 급변율 검사 추가 |
| 중복맥이 큰 사람에서 심박이 높게 나온다 | 중복맥 비 0.5~0.6 합성 자극에서 심박 오차 3.5~6.1%. 실측 기록의 중복맥 비는 99% 분위 0.30 | 여러 사람의 실측으로 분포 확인, 필요하면 중복맥 가드를 직전 RR에 비례하게 |
| 저역 필터 차단 주파수의 근거 수치를 실측으로 다시 잡아야 한다 | 이전 근거가 극성을 바꾸기 전의 합성 자극 수치였다 | 실측 기록으로 재측정 |
| ADC 샘플 주기를 상수로 둔다 | ADC 내부 발진기 오차만큼 RR 절대값이 달라진다. 판정은 비율이라 상쇄된다 | 보드에서 실측 보정 |

### 하드웨어와 시스템

| 한계 | 근거 | 후속 과제 |
|---|---|---|
| 보드를 제작하지 않았다 | PCB 제작과 착용 실측이 제출 범위 밖이다 | PCB 제작 뒤 RTL과 실측 대조 |
| 고개 떨굼 규칙은 착용 데이터로 검증되지 않았다 | 합성 시나리오와 가슴 가속도(이마 대용)로만 확인 | 착용 녹화로 검출률·헛울림 측정 |
| TIA 1단이 강한 빛에서 포화할 수 있다 | 위쪽 선형 한계 약 7 µA | 조명 조건별 DC 측정, 귀환 저항 조정이나 차광 |
| FPGA 시제품은 저전력이 아니다 | 약 74 mW, 대부분 정적 전력. 광원 약 53 mW | ASIC 이식, 광원 구동 방식 재설계 |
| 경보의 원인과 상태를 스마트폰이 모른다 | 경보 1바이트만 보낸다 | 필요하면 원인·상태 코드를 바이트에 싣기 |
| 장시간 착용성 | 헤어밴드 형태 | 모자·헬멧 내장 형태 |
