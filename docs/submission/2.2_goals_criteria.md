## 2.2 설계 목표 및 기준

### 2.2.1 설계 목표

앞서 살펴본 바와 같이 PPG는 조명과 조향에 무관하게 행동 이전의 변화를 측정할 수 있어, 기존 감시 방식이 비는 조건과 시점을 함께 메운다. 그러나 PPG에 나타나는 변화는 작아 단독으로는 졸음 검출에 부족할 수 있으며, 이 때문에 PPG는 다른 방법과 결합하는 보조 지표로 주로 쓰인다[17]. 본 과제는 이를 보완하기 위해, 졸음이 고개 떨굼이라는 명백한 행동으로 드러나는 순간을 IMU(관성 측정 장치)로 항상 함께 감시한다[18]. 심박은 이르지만 약한 신호이고 고개 떨굼은 늦지만 명백한 신호로, 두 채널은 서로의 약점을 메운다.

이에 본 설계는 이마의 PPG와 IMU로 운전 중 각성도 저하를 감지하고, 센서 입력부터 경보 출력까지를 칩 안에서 처리하는 졸음 감지 SoC를 목표로 한다.

### 2.2.2 설계 기준

설계 목표를 이루기 위해 설계가 만족해야 할 기준을 무엇을 어떻게 감지하는지(감지)와 칩 안에서 어디까지 처리하는지(구현)의 두 측면으로 나누어 정리하였다. 각 기준은 앞서 분석한 문제와 설계 목표에서 비롯된다.

| 구분 | 번호 | 기준 | 도출 근거 |
|---|---|---|---|
| 감지 | ① | 차량 거동(조향·차선)과 무관하게 동작한다 | 자율주행 중에는 차량 거동 기반 감시가 무력해진다 |
| | ② | 조명과 착용물(선글라스 등)의 영향을 받지 않는다 | 카메라 DMS는 역광·선글라스·얼굴 가림에 취약하다 |
| | ③ | 행동으로 드러나기 전의 신호로 판정한다 | 기존 방식은 졸음이 행동으로 드러난 뒤에야 검출한다 |
| | ④ | 사람마다 다른 평소 심박 수준에 영향받지 않고 판정한다 | 평소 심박 수준이 사람마다 크게 달라 공통 문턱이 서지 않는다 |
| | ⑤ | 고개 떨굼은 심박 판정과 별개로 상시 감시해 즉시 경보한다 | PPG 단독으로는 졸음 검출에 부족할 수 있다 |
| | ⑥ | 신뢰할 수 없는 신호로는 판정하지 않는다 | PPG의 변화가 작아 잡음이 졸음에 따른 변화처럼 보일 수 있다 |
| 구현 | ⑦ | 운행 내내 연속으로 판정한다 | 제어권 전환은 충분한 여유 없이 요구될 수 있다 |
| | ⑧ | 판정을 칩 안에서 끝내고 외부로는 경보만 보낸다 | 설계 목표, 그리고 카메라 DMS를 보완하는 채널이라는 역할 |

### 2.2.3 정량 사양

기준 가운데 수치로 정해지는 것은 다음과 같다. 박동을 안정적으로 검출하려면 심박 성분이 일정 진폭 이상이어야 하고, 맥박 간격을 판정에 쓰려면 봉우리 시각의 해상도가 곧 간격 오차가 되므로 충분한 표본화율이 필요하다. 이 두 조건이 아날로그 이득과 ADC 설정을 정한다.

| 항목 | 값 | 근거 | 관련 기준 |
|---|---|---|---|
| 심박 성분 진폭 | ADC 20 카운트(p-p) 이상 | 봉우리 검출이 박동을 안정적으로 잡는 최소 진폭 | ③ |
| PPG 표본화 | 240 SPS, 12비트 | 맥박 간격 분석에 필요한 시간 해상도[19][20] | ③, ④ |
| 신호 대역 | 0.159–15.9 Hz | 심박 대역 0.5–4 Hz(30–240 bpm)를 고른 이득으로 통과시키고 표본화 전에 고주파를 제거 | ③ |
| 관성 센서 | 6축, 100 Hz | 고개 떨굼 감지 | ⑤ |

다음 절에서는 이 기준을 만족시키기 위한 설계 방향을 다룬다.

> 확인: 20 카운트, 신호 대역, 6축 100 Hz는 하드웨어 담당 원고의 값이다.

> 확인: 검증 방법(학습에 쓰지 않은 사람으로 평가, 기준 모델과 비트 일치, 헛경보 시간당 4회 고정)은 기준이 아니라 절차라서 2.4 구현 범위로 옮겼다.

> 확인: 2.3의 결정 표는 아직 옛 기준 ①~⑥을 쓴다. 2.3을 쓸 때 새 번호(①~⑧)로 바꾼다.
