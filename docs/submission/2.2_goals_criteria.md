## 2.2 설계 목표 및 기준

### 2.2.1 설계 목표

앞서 살펴본 바와 같이 PPG는 조명과 조향에 무관하게 행동 이전의 변화를 측정할 수 있어, 기존 감시 방식이 비는 조건과 시점을 함께 메운다. 그러나 PPG에 나타나는 변화는 작아 단독으로는 졸음 검출에 부족할 수 있으며, 이 때문에 PPG는 다른 방법과 결합하는 보조 지표로 주로 쓰인다[17]. 이를 보완하기 위해 졸음이 고개 떨굼이라는 명백한 행동으로 드러나는 순간을 IMU(관성 측정 장치)로 항상 함께 감시한다[18]. 심박은 이르지만 약한 신호이고 고개 떨굼은 늦지만 명백한 신호로, 두 채널은 서로의 약점을 보완한다.

이에 본 설계는 이마의 PPG와 IMU로 운전 중 각성도 저하를 감지하고, 센서 입력부터 경보 출력까지를 칩 안에서 처리하는 졸음 감지 SoC를 목표로 한다.

### 2.2.2 설계 기준

앞서 정의한 문제와 설계 목표로부터 도출한 기준을 감지와 구현의 두 측면으로 정리하고, 기준마다 충족 여부를 판단할 목표를 두었다. 판정 성능은 학습에 쓰지 않은 사람의 데이터로, 헛경보를 시간당 4회로 고정한 조건에서 각성도 저하 구간 단위 민감도로 평가한다.

| 구분 | 번호 | 기준 | 목표 |
|---|---|---|---|
| 감지 | ① | 현재 각성 상태의 실시간 판정 | 5초마다 최근 60초 신호로 판정 갱신 |
| | ② | 사람·착용 상태에 따른 신호 차이에 무관한 판정 | 최악 광학 조건 박동 진폭 20 카운트 이상 |
| | ③ | 심박 판정과 독립적인 고개 떨굼 상시 감시 | 심박 판정 보류 중 떨굼 경보 누락 0 |
| | ④ | 신뢰할 수 없는 신호·고장 상태에서 판정 보류 | 주입 고장 검출·복구 100%, 품질 미달 창 판정 0 |
| 구현 | ⑤ | 칩 내부 판정, 경보만 무선 송신 | 경보 1회당 1바이트, 송신 누락 0, BLE 모듈 실물 전달 확인 |
| | ⑥ | 칩에 들어가는 소형 판정 회로 | 판정 블록 나눗셈기·블록 메모리 0, 12 MHz 타이밍 충족, 정수화 후 기준 모델 대비 불일치 0 |

*표 2. 설계 기준과 목표*

> 확인: ①의 20 카운트, ③의 고장 주입, ⑤의 FPGA 수치는 하드웨어 담당 원고의 값이다. 담당과 맞출 것.

> 확인: 판정 성능은 합격선을 목표로 두지 않았다. EU 기준(평균 민감도 40% 초과)은 모델 0.413은 넘지만 칩 0.379는 못 넘고 라벨 체계도 달라, 3.4에서 조건을 달아 비교한다.

> 확인: 정량 사양 소절은 없앴다. 20 카운트와 표본화율은 3.2 신호 예산, 성능 비교는 3.4에서 다룬다. 2.4 구현 범위 초안의 헛경보 조건 문장은 여기와 겹치므로 2.4를 쓸 때 정리한다.

> 확인: 2.3의 결정 표는 아직 옛 기준을 쓴다. 2.3을 쓸 때 새 번호(①~⑥)로 바꾼다.
