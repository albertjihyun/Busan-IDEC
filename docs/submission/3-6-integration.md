## 3.6 통합 검증과 결과

블록별 검증은 각 절(3.2~3.5)에 적었다. 이 절은 세 블록을 이은 칩 전체의 검증과 결과 종합이다.

> 확인: 시스템 최상위를 제출물에 넣을지 팀 결정. 넣지 않으면 3.6.1~3.6.2를 "블록 간 연결 시험"으로 줄인다.

### 3.6.1 시스템 최상위

신호처리·판정·통신 세 블록을 선으로 잇고, 새 로직으로는 파워온 리셋 하나만 더했다. Cmod A7의 버튼은 액티브 하이라 리셋에 바로 물리지 않고, 컨피규레이션 직후 16클럭 동안 리셋을 내린다. 세 블록의 리셋 방식(비동기·동기)이 다르지만 같은 12 MHz 도메인에서 같은 리셋을 쓰므로 문제없다. 핀은 여섯 개(클럭, SCL, SDA, LED, BLE 송신, BLE 웨이크)이고 신호처리 블록의 디버그 출력은 잇지 않아 합성에서 지워진다.

### 3.6.2 칩 전체 시험

센서 보드 쪽은 ADC(MCP3421)와 IMU(ICM-42670-P)의 와이어 레벨 슬레이브 모델로 두고, I2C 100 kHz로 40초를 돌렸다.

| 항목 | 결과 |
|---|---|
| ADC와 IMU가 버스 하나를 나눠 씀 | ADC 샘플 손실 0 |
| 자이로 끄덕임 전달 | 끄덕임 4회, 떨군 채 유지 1회가 판정 블록까지 전달 |
| 자이로 부호 게이트 | 부호 확정(14.45초) 전의 끄덕임 1회는 경보가 되지 않음 |
| 경보 → 통신 | 경보 5개 → UART `0x01` 5바이트 |
| BLE 웨이크 | 항상 High |
| 7개 항목 | 7/7 통과 |

공개 데이터의 실측 신호를 칩 전체에 흘리는 시험도 했다. WildPPG 참가자 1명의 이마 PPG와 이마 가속도 30분을 ADC·IMU 입력으로 재생했다(I2C는 동작 모델). 신호처리부터 통신까지 끝까지 연결되어 동작했다. 이 구간은 등산 기록이라 박동의 61%가 탈락하고 판정 창의 91%가 보류되어 심박 경보는 0이었다. 이 기록에는 자이로가 없어 끄덕임 경로는 시험하지 못했다.

> 확인: 같은 시험의 가속도 자세 경보 23회는 이 기록의 센서 축 방향이 확정되지 않아 해석할 수 없다. 넣지 않았다.

### 3.6.3 구현 결과

Vivado 2026.1, xc7a35tcpg236-1, 시스템 최상위 배치·배선 결과(12 MHz).

| 항목 | 값 |
|---|---|
| LUT | 3,634 (17.5%) — 신호처리 3,413, 판정 207, 통신 14 |
| FF | 3,656 (8.8%) |
| DSP48E1 | 4 — 저역 FIR 1, 판정식 3 |
| BRAM | 1 — 기저선 제거 지연선 |
| WNS | 54.8 ns (주기 83.3 ns) |
| DRC | 에러 0 |
| 게이트 환산 (Yosys) | 약 5.5만 NAND2 + 메모리 약 14 kbit |
| 전력 추정 | 약 74 mW = 정적 70 + 동적 4 (신호처리 3, 판정·통신 약 0). 토글률 기본값, 신뢰도 Medium |

전력의 대부분은 FPGA 정적 전력이다. 같은 연산을 저전력 MCU로 하면 데이터시트 계산으로 약 0.2 mW이고(2.4 결정 3), 기기 전력에서는 광원(약 53 mW)이 가장 크다.

### 3.6.4 결과 종합

**블록별 검증.**

| 블록 | 방법 | 결과 |
|---|---|---|
| 아날로그 프론트엔드 | 손가락 브레드보드 측정, 회로도와 설계 가정 대조 | 82 bpm, 358 mVpp, 중복맥 확인. 대역·기준·주소 일치 |
| 신호처리 | 파이썬 골든 모델 비트 대조, I2C·고장·IMU·LED 시험, 실측 PPG 재생 | 골든 불일치 0, 단위 시험 전부 통과, 깨끗한 실측 120초에서 심박 오차 2.8% |
| 판정 | 파이썬 정수 기준 모델 비트 대조 75,464블록, 떨굼 16 시나리오 | 불일치 0 |
| 통신 | 모든 펄스 간격, 무작위 1,000펄스, 판정 벡터 연결 | 14/14, 경보 3,154 = 바이트 3,154 |
| 칩 전체 | 와이어 레벨 모델로 40초, 실측 신호 30분 | 7/7, ADC 손실 0 |

**판정 성능.** 성능 숫자는 두 종류라 섞지 않는다.

| 구분 | 값 | 뜻 |
|---|---|---|
| 처음 보는 사람에 대한 성능 (LOSO, 헛경보 4회/h) | 사건 민감도 0.413 [0.28–0.53], 깊은 구간 0.633 [0.48–0.80] | 모델이 새 사람에게 통하는 정도 |
| 칩 재현 (정수 문턱 + 판정 규칙, 50명) | 사건 민감도 0.379, 깊은 구간 0.567, 헛경보 3.94회/h | 칩이 모델을 그대로 구현한다는 확인 |
| 실제로 울리는 경보 (30초 간격 적용 뒤) | 깨어 있을 때 시간당 26번, 피로 1단계 이상일 때 45번 | 스마트폰이 받는 바이트 수 |
| 이마 PPG 전이 (WildPPG 15명) | ECG 대비 `mean_rb` 차이 중앙값 −0.1%, 표준편차 1.7%, 판정 일치 97.4% | ECG로 배운 문턱이 이마 PPG에서도 같게 동작 |

헛경보 3.94회/h는 60초 안에 이어진 경보를 한 덩어리로 센 판정 지표이고, 시간당 26번은 스마트폰이 받는 바이트 수라 세는 대상이 다르다.
