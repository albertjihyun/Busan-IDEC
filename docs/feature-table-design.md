# 특징 표 설계서 (2단계)

담당: 유지현 | 작성: 2026-09-18 | 상태: 설계 확정(B 포함, 9/18), 구현 전

1단계 결과(`data/interim/rr/*.npz`, 50명의 봉우리·RR·SQI·라벨)를 3단계 모델이 먹을 표 `data/processed/features_{30,60}s.csv`로 바꾸는 규칙을 적는다. 특징 후보를 왜 이렇게 골랐는지는 [feature-rationale.md](./feature-rationale.md), 회로 쪽 재료 정의는 [datapath-request.md](./datapath-request.md) ③ 절. 이 문서는 그 둘 사이, "재료를 어떻게 표로 만드나"만 다룬다.

설계 원칙은 하나다. **칩이 실제로 놓이는 조건 그대로 표를 만든다.** 칩이 가질 수 없는 정보(라벨, 개별 RR 값, 미래)를 표를 만드는 데 쓰지 않는다. 학습 성적이 실제 성능보다 좋게 나오는 것을 막기 위해서다.

## 1. 입력과 출력

입력: 사람마다 `peaks`(240 Hz 봉우리 인덱스), `rr`(봉우리 간격, 샘플 수), `ok`(SQI 통과), `labels`(30초 에폭 라벨, 0~4, 아티팩트 −1).

출력: 표 두 장. 행과 정답 열은 완전히 같고, 특징 열을 계산한 구간만 30초 / 60초로 다르다.

## 2. 행: 30초 에폭 하나

행 하나 = 피험자 한 명의 30초 에폭 하나. 에폭 k는 샘플 [7200k, 7200(k+1)), 즉 시각 [30k, 30k+30) 초. 판정 시각은 에폭 끝(30, 60, 90, … 초)이다.

- 정답은 **그 에폭의 라벨 하나**다. 창 길이와 무관하다. 60초 창은 정답을 두 에폭에서 합치는 것이 아니라, 같은 에폭의 정답을 맞히기 위해 앞 에폭의 심박까지 입력으로 보는 것이다.
- 5초마다 갱신되는 중간 창(5~35초 등)은 표에 넣지 않는다. 라벨이 30초 단위라 정답이 없다. 5초 갱신 시의 헛경보 추정은 5단계에서 따로 한다.
- 에폭 번호는 0부터. 라벨 파일의 에폭 1이 EDF 녹화 시작과 같다고 본다(전제, 8절).

## 3. 재료 → 창

`src/window_acc.WindowAcc`를 그대로 쓴다. 준용 회로와 같은 절차다.

- SQI 통과 RR만 다섯 재료(N, ΣRR, ΣRR², Σd, Σd²)에 더한다. d = RR − 직전 누산 RR. `rr_prev`는 블록 경계에서 초기화하지 않는다. 기록의 첫 RR만 d가 없다.
- 1200샘플(5초)마다 한 벌을 닫는다. 30초 창 = 최근 6벌 합, 60초 창 = 최근 12벌 합.
- 에폭 k의 행은 블록 6(k+1)이 닫힐 때의 창이다. 30초 창은 에폭 k와 정확히 겹친다. 60초 창은 에폭 k−1과 k를 덮는다. 에폭 0의 60초 창은 블록이 6벌뿐이라 없음(`valid = 0`, 사유 `no_window`).
- RR이 어느 블록에 들어가는지는 봉우리 위치 기준으로 한다. 회로는 확정 시점(봉우리보다 최대 24샘플 늦음) 기준이라 블록 경계에서 박동 하나가 옆 블록으로 갈 수 있다. 표에는 영향이 없고, 4단계 정답지는 파형에서 다시 흘려 회로와 같은 시점으로 만든다.

단위는 전부 샘플 수(240 Hz, 1샘플 = 4.17 ms). ms로 바꾸지 않는다. 그림에서만 ms로 표시한다.

## 4. 1차 특징 8개 (+ 비교용 median)

| 열 | 뜻 | 식 (재료만 사용) |
|---|---|---|
| `mean_nn` | 평균 간격 (빠르기) | ΣRR / N |
| `sdnn` | 간격의 표준편차 (흔들림 총량) | √(ΣRR²/N − mean²) |
| `rmssd` | 이웃 차이의 크기 (빠른 흔들림) | √(Σd²/N) |
| `sdsd` | 이웃 차이의 표준편차 | √(Σd²/N − (Σd/N)²) |
| `cvnn` | SDNN / mean | |
| `cvsd` | RMSSD / mean | |
| `sd2` | 포인카레 긴 축 (느린 흔들림) | √(2·SDNN² − RMSSD²/2) |
| `sd12` | SD1 / SD2, SD1 = RMSSD/√2 | |
| `median_nn` | 비교용. 창 안 RR의 중앙값 | RR 배열에서 직접. 회로 후보 아님 |

규약:

- 분산은 N으로 나눈다(N−1 아님). RMSSD²은 Σd²/N (d 개수가 아니라 N). 모두 창에 일정하게 걸리는 편향이라 임계값이 흡수하고, 회로가 d 개수를 따로 세지 않아도 된다.
- `sdnn`, `sdsd`의 제곱근 안은 수학적으로 음수가 아니다. 정수 회로에서는 N·ΣRR² − (ΣRR)² 꼴로 계산하면 정확히 0 이상이다(4단계).
- `sd2`의 제곱근 안(2·SDNN² − RMSSD²/2)은 **음수가 될 수 있다.** 이웃 차이가 전체 흔들림을 지배할 때(한 박마다 번갈아 뛰는 패턴, 가짜 봉우리, 이소성 박동)다. 음수면 0으로 자른다(`sd2 = 0`). `sd12`는 SD2가 0에 가까우면 발산하므로 분모를 1샘플(4 ms) 아래로 내리지 않는다. 몇 행에서 잘렸는지 센다.

## 5. 파생 특징 6개

mean_nn, sdnn, rmssd 셋에 대해 "개인 기준선 대비"와 "직전 창 대비"를 만든다. 사람 간 기저 차이가 졸음에 의한 차이보다 커서 절대값만으로는 비교가 안 되기 때문이다. 근거는 Vicente 2016(운전 졸음, 첫 3분 기준선 뺄셈 + 직전 1분 차이)과 Lu 2022 리뷰의 개인화 권고.

### 5.1 개인 기준선

- **기준선 = 첫 3분 동안 나온 창 특징값의 평균.** 30초 창이면 에폭 0~5의 여섯 값, 60초 창이면 에폭 1~5의 다섯 값. Vicente가 쓴 방식 그대로("feature mean value of the first three minutes"). 3분치 재료를 따로 누산해 한 번에 계산하는 방식은 쓰지 않는다. 3분짜리 SDNN은 30초짜리 SDNN보다 체계적으로 커서(느린 흔들림이 더 들어옴) 같은 종류의 값이 아니기 때문이다. 기준선은 비교 대상과 같은 창 길이로 만든 값이어야 한다.
- 무효 창(6절)은 평균에서 뺀다. 유효 창이 절반 미만이면 기준선 무효(`base_ok = 0`). 그 사람의 기준선 특징은 세션 내내 중립값이고, 3단계에서 이런 사람이 몇 명인지 보고한다.
- **라벨을 보지 않는다.** 첫 3분이 피로여도 그대로 기준선이다(22번은 세션 전체가 피로, 04·13번은 첫 에폭이 피로). 칩은 라벨을 모르므로 학습도 같은 조건이어야 한다. Persson 2021은 KSS가 낮은 구간을 골라 기준선으로 썼는데 이는 사후 분석에서만 가능하다.
- 길이 3분의 근거: Vicente 2016 선례. 우리 데이터에서 첫 3분이 전부 각성인 사람 47/50 (5분 46, 10분 43). 3분이면 박동 약 200개.
- 비교 방식은 둘 다 열로 둔다. **나눗셈**(`*_rb` = 지금 / 기준선)이 정식 후보, **뺄셈**(`*_db` = 지금 − 기준선)은 비교용. 선례는 뺄셈이고, 나눗셈은 기저 심박이 다른 사람을 같은 자로 재는 장점이 있다. 어느 쪽이 나은지 3단계에서 데이터로 고른다. 회로에서 나눗셈 판정 `x / b > θ`는 `x > θ·b`로 바꿔 곱셈 하나다.
- 기준선이 아직 없는 첫 3분(에폭 0~5)은 **판정 보류**(`valid = 0`, 사유 `baseline`). 경위는 8절 B.

회로 비용: 특징 셋에 대해 첫 6개 출력의 합을 담는 레지스터 셋. 6으로 나누는 대신 `6·x` 대 `θ·합`을 비교하면 나눗셈이 없다.

### 5.2 직전 창 대비

- `*_dp` = 지금 창 값 − **30초 전** 창 값. 5초 전 창은 25초가 겹쳐 변화가 거의 0이라 정보가 없다. 30초 전은 채점 주기와 같고, Vicente의 "직전 1분 대비 차이"를 우리 출력 주기로 옮긴 것이다.
- 직전 창이 무효(N 부족)면 0(중립).
- 회로 비용: 6블록 전 창 값 셋을 담는 레지스터.
- Vicente의 결과에서 상위 특징 5개에 기준선 대비 계열은 여러 개 들어갔지만 직전 대비 계열은 하나도 없었다. 30초 SDNN·RMSSD 두 개의 차는 추정 오차가 겹쳐 잡음이 크므로, 3단계에서 탈락할 가능성이 높다고 본다. 후보에 두는 이유는 시도한 기록을 남기기 위해서다.

## 6. 유효성

행은 지우지 않고 `valid`와 `reason`으로 표시한다. 3단계 학습·채점은 `valid = 1`만 쓴다. 행을 남기는 이유는 직전 창 대비 계산과 커버리지 집계에 필요해서다.

| 사유 | 조건 | 표시 |
|---|---|---|
| 아티팩트 | 에폭 라벨이 Severe Artifacts / Signal Abnormality | `y = −1`, `valid = 0`, `reason = artifact` |
| 박동 부족 | 30초 창 N < 15, 60초 창 N < 30 | `valid = 0`, `reason = low_n` |
| 기준선 준비 중 | 에폭 0~5 | `valid = 0`, `reason = baseline` |
| 창 없음 | 60초 표의 에폭 0 | `valid = 0`, `reason = no_window` |

박동 부족 기준 15의 근거: SQI 상한 1.5초이면 박동이 하나도 안 떨어졌을 때 30초에 최소 20박이다. 15박은 30 bpm에 해당해 살아 있는 운전자의 정상 심박으로는 나올 수 없으므로, 15 미만은 신호 문제가 확실하다. 실측 분포(50명 12,531창): 중앙값 36박, 95%가 28박 이상, 15 미만 0.50%, 20 미만 0.97%. 20 미만 122창 중 114창이 26번(47 bpm + 가짜 봉우리로 SQI 탈락 19%). 15로 하면 26번의 24%를 잃고, 20이면 46%를 잃는다. 60초는 같은 비율로 30.

칩에서 이 규칙은 "N < 기준이면 판정 보류"이고 비교기 하나다. 보류 비율이 커버리지이며, 성적 옆에 항상 같이 적는다.

## 7. CSV 열

`features_30s.csv`, `features_60s.csv` 공통. 한 행 = (sid, epoch).

| 묶음 | 열 |
|---|---|
| 키 | `sid`, `epoch`, `t_end_s` |
| 정답 | `label`(원본 0~4, 아티팩트 −1), `y`(0 / 1 이상 → 1, 아티팩트 −1) |
| 유효성 | `valid`, `reason`, `in_baseline`(에폭 0~5), `base_ok` |
| 재료 | `n`, `sum_rr`, `sum_rr2`, `sum_d`, `sum_d2` |
| 1차 | `mean_nn`, `sdnn`, `rmssd`, `sdsd`, `cvnn`, `cvsd`, `sd2`, `sd12`, `median_nn` |
| 기준선 대비 | `mean_rb`, `sdnn_rb`, `rmssd_rb` (비), `mean_db`, `sdnn_db`, `rmssd_db` (차, 비교용) |
| 직전 대비 | `mean_dp`, `sdnn_dp`, `rmssd_dp` |

재료 열을 남기는 이유: 4단계 정수 변환과 판정 테스트 벡터를 이 표에서 그대로 만들기 위해서다.

특징 수 셈: 1차 8 + 파생 6 = 14. `median_nn`과 `*_db`는 비교용이라 세지 않는다.

## 8. 검토에서 나온 쟁점

설계를 적고 나서 다시 훑으며 찾은 것. 결정이 바뀐 것과 열어 둔 것을 구분한다.

### 바뀐 것

**A. 기준선 계산 방식.** 처음 안은 "첫 3분 재료를 따로 누산해 한 번에 계산"이었다. 이러면 기준선 SDNN이 3분짜리가 되어 30초짜리 SDNN과 종류가 다르고, 비 1.0이 "변화 없음"을 뜻하지 않게 된다. **창 특징값의 평균**으로 바꿨다(5.1). Vicente의 방식과도 같다.

**B. 첫 3분 행의 처리.** 처음 안은 파생 열을 중립값(비 1.0, 차 0)으로 채우고 표시 열을 두는 것이었다. 검토에서 문제를 찾았다. 중립값이 **정확히** 1.0 / 0이면 모델(특히 트리)이 "이 값이면 세션 초반 = 대체로 각성"이라는 규칙을 배울 수 있다. 계획서가 경과 시간을 입력에서 금지한 이유가 이것이고, 중립값 채움은 경과 시간을 뒷문으로 넣는 셈이다. 칩도 같은 값을 내므로 엄밀히는 누출이 아니지만, "운전 시작 때는 깨어 있다"는 실험 설계의 사정을 모델이 외우는 것이라 시작부터 졸린 운전자에게는 통하지 않는다.

**판정 보류**로 확정했다(9/18). 첫 3분은 `valid = 0`이고 학습·채점에서 빠진다. 칩도 첫 3분은 기준선을 만드는 동안 판정하지 않는다(워밍업). 잃는 것: 세션당 3분 = 커버리지 2.5%, 첫 3분 안의 사건(04·13·22번 초반, 09번은 3분부터라 경계). 이 사건들은 놓침이 아니라 판정 불가로 센다. 대안(중립값 채움 + 학습에서만 제외)은 칩 동작과 학습 조건이 갈라져서 택하지 않았다.

### 열어 둔 것

**C. 라벨 시각 정렬.** 주석 파일의 첫 시각과 EDF 헤더 시작 시각이 50명 전원 다르다(대부분 4~17초, 42번은 20분). EDF 길이가 에폭 수 × 30초와 정확히 맞아(01번 7203초 ↔ 240에폭, 42번 8851초 ↔ 295에폭) 주석은 EDF 타임라인 위에 매겨진 것으로 보고 "에폭 1 = EDF 시작"을 유지한다. 1단계도 같은 전제였다. 틀렸다면 라벨이 최대 반 에폭 어긋나는 것이고, 30초 사건의 경계가 흐려지는 정도다. 데이터셋 제작자에게 물어볼 수 있으면 확인한다.

**D. 26번.** 느린 심박(47 bpm)에 1단계에서 확인한 가짜 봉우리 문제가 겹쳐 SQI가 19%를 떨어뜨린다. 표에는 넣고 3단계에서 성적을 본다. 근본 원인은 SQI의 25% 급변 규칙이 번갈아 뛰는 패턴을 연쇄 탈락시키는 것인데, 준용에게 이미 준 규칙이라 지금 고치지 않는다. PPG-DaLiA로 급하강 조건을 다시 볼 때(19일 이후) 같이 본다.

**E. 05·47번.** 아티팩트가 절반이지만 남은 절반은 SQI 통과 100%·98.9%로 멀쩡하다. 표에 넣는다. 3단계에서 이 두 사람만 성적이 이상하면 그때 뺀다.

**F. 60초 창의 희석.** 60초 창은 정답 에폭 앞의 30초를 입력에 섞는다. 30초짜리 사건(23%)은 항상 각성 30초와 반씩 섞인다. 값이 안정되는 이점이 이 손실을 넘는지는 3단계에서 같은 정답으로 비교해 정한다. 표를 두 장으로 나눈 것은 실무 편의이고 행·정답은 같다.

**G. 헛경보의 시간 단위.** 표는 30초마다 한 행이지만 칩은 5초마다 판정한다. 3단계의 "시간당 헛경보"는 30초 판정 기준이고, 5초 갱신 기준으로는 최대 6배까지 다를 수 있다. 5단계에서 5초 행을 만들어 다시 잰다.

## 9. 표가 나오면 먼저 볼 것

모델을 돌리기 전에 아래 순서로 본다. 결과는 `docs/features.md`에 적는다.

1. **계산 검증.** 15개 특징 × 창 2종 히스토그램. mean_nn 150~300샘플(600~1250 ms), sdnn 5~30샘플, sd12 대체로 1 미만, 음수 없음. `sd2` 절단 행 수.
2. **집계표.** 창 길이별 행 수, 유효 행 수, 무효 사유별 수, 각성 대 피로 비율, `base_ok = 0`인 사람.
3. **방향 재현.** 문헌에서 유일하게 일치한 방향은 "졸리면 mean_nn 증가". 전체를 섞은 분포는 사람 간 차이에 묻히므로, **사람 안 짝 비교**(피험자마다 피로 중앙값 − 각성 중앙값, 47명)로 판단한다. 재현되면 제출 문서에 적고, 안 되면 시뮬레이터·뇌파 라벨 특성으로 원인을 따진다.
4. **상관 행렬.** 0.95 넘는 쌍을 표시만 한다(sdsd–rmssd, cvsd–rmssd 등 예상). 빼는 것은 3단계 학습 폴드 안에서.
5. **덤.** `gt`(정답 봉우리)로 같은 특징을 뽑아 우리 봉우리 결과와 비교. 봉우리 오차가 특징에 얼마나 번지는지 숫자 하나로 남긴다. 시간이 밀리면 뺀다.
